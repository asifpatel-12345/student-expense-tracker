# 🎓 Student Budget & Expense Tracker

A lightweight, interactive, and responsive web application designed for students and individuals to manage their monthly budget, track daily expenses, and monitor remaining balance in real time.

---

## 🌟 Features

- **Dashboard Summary:** Real-time calculation of Total Budget, Total Spent, and Remaining Balance.
- **Budget Setup:** Set and update your monthly budget anytime.
- **Categorized Expenses:** Add expenses along with category tags (🍔 Food, 🚌 Travel, 📚 Books, 🏠 Rent, 🎉 Other).
- **Expense History:** View a clean history list of all added expenses with instant delete support.
- **Data Persistence:** Uses Browser `localStorage` to save budget and expense data so information is preserved even after refreshing or closing the browser.
- **Responsive UI:** Clean, modern design built with pure CSS.

---

## 🛠️ Tech Stack

- **HTML5:** Page structure and layout elements.
- **CSS3:** Custom styling, layout design, and card UI.
- **JavaScript (ES6):** DOM manipulation, event handling, data operations, and `localStorage` management.
